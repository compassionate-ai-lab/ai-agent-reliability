# Release decision record

Identify source and target releases, affected obligations, evidence reused, evidence refreshed, task population, assistance, budgets, evaluator, confidence plan, profile counts, unknowns, exclusions, critical-stratum floors, and hard gates.

Record migration compatibility, pending-operation reconciliation, current human-review capacity, rollback test, monitoring, decision owner, permitted envelope, and evidence-expiry triggers. Choose a disposition: proceed within scope, restrict effects, require review, collect evidence, repair, or stop.
